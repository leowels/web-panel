# 🔧 Исправление ошибки ERR_CONNECTION_REFUSED при входе

## Проблема
```
POST http://localhost:8000/api/auth/login net::ERR_CONNECTION_REFUSED
```

## Решение

### Вариант 1: Если Frontend и Backend в одном контейнере

В переменных окружения Timeweb Cloud установите:
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
BACKEND_URL=http://localhost:8000
```

И проверьте, что Backend запущен (в логах должны быть сообщения о запуске).

### Вариант 2: Использовать прокси Next.js (рекомендуется)

Я добавил прокси в `next.config.js`. Теперь можно использовать относительный путь:

В переменных окружения установите:
```env
NEXT_PUBLIC_API_URL=/api
```

Или оставьте пустым - будет использоваться прокси.

### Вариант 3: Использовать внешний URL Backend

Если Backend на отдельном домене:
```env
NEXT_PUBLIC_API_URL=https://api.yourdomain.com
```

## Проверка

### 1. Проверьте логи контейнера

В Timeweb Cloud откройте логи и проверьте:
- ✅ Backend запущен: `INFO: Uvicorn running on http://0.0.0.0:8000`
- ✅ Frontend запущен: `Ready on http://0.0.0.0:3000`
- ❌ Нет ошибок подключения

### 2. Проверьте переменные окружения

Убедитесь, что установлены:
- `NEXT_PUBLIC_API_URL` (для одного контейнера: `http://localhost:8000`)
- `SECRET_KEY` (для Backend)
- `DATABASE_URL` (для Backend)

### 3. Проверьте порты

- Порт 3000 должен быть открыт для Frontend
- Порт 8000 должен быть доступен внутри контейнера (для Backend)

## Быстрое исправление

1. **В Timeweb Cloud:**
   - Откройте настройки приложения
   - Добавьте переменную: `NEXT_PUBLIC_API_URL=http://localhost:8000`
   - Сохраните и перезапустите контейнер

2. **Проверьте логи:**
   - Убедитесь, что Backend запущен
   - Убедитесь, что нет ошибок

3. **Попробуйте войти снова**

## Если все еще не работает

1. **Проверьте, что Backend запущен:**
   - В логах должны быть сообщения от uvicorn
   - Если нет - проверьте переменные окружения Backend

2. **Проверьте CORS:**
   - `CORS_ORIGINS` должен содержать ваш домен
   - Или `*` для разработки (не рекомендуется для production)

3. **Проверьте базу данных:**
   - `DATABASE_URL` должен быть правильным
   - База данных должна быть доступна
