# 🔧 Исправление: Backend не запускается

## Проблема

В логах видно только Frontend:
```
✓ Ready in 140ms
▲ Next.js 14.2.33
```

Но нет логов от Backend (FastAPI).

## Причина

Backend либо не запускается, либо его логи не выводятся в консоль.

## Решение

Я обновил `docker-entrypoint.sh`:
1. ✅ Добавлен вывод логов Backend в консоль
2. ✅ Добавлена проверка запуска Backend
3. ✅ Добавлены сообщения о статусе запуска

## Что нужно сделать

### 1. Закоммитьте обновленный скрипт:

```bash
git add docker-entrypoint.sh
git commit -m "fix: исправлен запуск Backend и вывод логов"
git push
```

### 2. Пересоберите контейнер в Timeweb Cloud

После push контейнер должен автоматически пересобраться.

### 3. Проверьте логи

После пересборки в логах должны быть:
```
=== Запуск Backend на порту 8000 ===
Backend запущен с PID: X
INFO:     Uvicorn running on http://0.0.0.0:8000
=== Запуск Frontend на порту 3000 ===
Frontend запущен с PID: Y
✓ Ready in 140ms
```

## Если Backend все еще не запускается

### Проверьте переменные окружения:

```env
SECRET_KEY=<должен_быть_установлен>
DATABASE_URL=postgresql://user:password@host:5432/dbname
PORT=8000
ENVIRONMENT=production
```

### Проверьте базу данных:

- База данных должна быть создана
- `DATABASE_URL` должен быть правильным
- База данных должна быть доступна

### Проверьте права доступа:

- Убедитесь, что пользователь `appuser` может выполнять Python скрипты
- Убедитесь, что все файлы скопированы правильно

## Альтернативное решение

Если проблема сохраняется, можно запустить Backend отдельно:

1. Создайте второй контейнер для Backend
2. Используйте `backend/Dockerfile`
3. Настройте переменные окружения
4. Обновите `NEXT_PUBLIC_API_URL` на URL Backend контейнера
