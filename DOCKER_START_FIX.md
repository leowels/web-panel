# ✅ Исправление: "next: not found" в Docker

## Проблема
```
sh: next: not found
```

## Причина

В standalone режиме Next.js создает самодостаточный сервер без установки `next` в production образе. Команда `npm start` не работает, потому что `next` не установлен.

## Решение

Использовать `node server.js` вместо `npm start` для standalone режима.

## Что было исправлено:

1. ✅ Изменена команда запуска в Dockerfile: `CMD ["node", "server.js"]`
2. ✅ Standalone режим уже включен в `next.config.js`

## Структура standalone:

В standalone режиме Next.js создает:
- `server.js` - точка входа сервера
- `node_modules/` - только необходимые зависимости
- `.next/static/` - статические файлы
