# 🔧 Исправление ошибки входа

## Проблемы:

1. **Основной порт в Timeweb Cloud = 8000** (должен быть 3000)
2. **ADMIN_PASSWORD не установлен** в переменных окружения

## Решение:

### 1. Изменить основной порт в Timeweb Cloud:

- Откройте настройки приложения
- Найдите "Порт" или "Основной порт"
- Измените с **8000** на **3000**
- Сохраните и перезапустите

### 2. Установить ADMIN_PASSWORD:

В переменных окружения Timeweb Cloud добавьте:

```env
ADMIN_PASSWORD=ваш_пароль_админа
```

**Важно:** Используйте надежный пароль!

### 3. Учетные данные для входа:

После установки `ADMIN_PASSWORD`:
- **Username:** `admin`
- **Password:** значение из `ADMIN_PASSWORD`

Если `ADMIN_PASSWORD` не установлен, используется пароль по умолчанию: `admin123`

### 4. Проверить CORS:

Убедитесь, что в переменных окружения есть:

```env
CORS_ORIGINS=https://leowels-web-panel-e5fe.twc1.net,http://localhost:3000
```

Замените `https://leowels-web-panel-e5fe.twc1.net` на ваш реальный домен.

## После исправления:

1. Перезапустите приложение
2. Попробуйте войти с учетными данными:
   - Username: `admin`
   - Password: значение из `ADMIN_PASSWORD` (или `admin123` если не установлен)
