# 🚀 Деплой в Timeweb Cloud

## ✅ Сборка завершена успешно!

Ваш Docker образ собран и готов к деплою в Timeweb Cloud.

## 📋 Следующие шаги:

### 1. Проверьте статус деплоя в Timeweb Cloud

1. Войдите в [панель управления Timeweb Cloud](https://timeweb.cloud)
2. Перейдите в раздел **"Приложения"** или **"Контейнеры"**
3. Найдите ваше приложение
4. Проверьте статус деплоя (должен быть "Запущено" или "Работает")

### 2. Настройте переменные окружения (КРИТИЧНО!)

В настройках приложения в Timeweb Cloud добавьте следующие переменные:

#### Обязательные переменные:

```env
SECRET_KEY=<сгенерируйте_сильный_ключ>
DATABASE_URL=postgresql://user:password@host:5432/dbname
CORS_ORIGINS=https://yourdomain.com,https://www.yourdomain.com
ENVIRONMENT=production
ADMIN_PASSWORD=<сильный_пароль_для_админа>
```

#### Для AI (если используете):

```env
AI_PROVIDER=timeweb
AI_API_KEY=<ваш_ключ_от_timeweb_ai>
AI_BASE_URL=<url_вашего_ai_агента>
AI_AGENT_ACCESS_ID=<access_id_вашего_агента>
AI_MODEL=<модель_если_нужна>
```

#### Для Frontend:

```env
NEXT_PUBLIC_API_URL=https://api.yourdomain.com
```

### 3. Генерация SECRET_KEY

Если нужно сгенерировать SECRET_KEY:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Или в Python:
```python
import secrets
print(secrets.token_urlsafe(32))
```

### 4. Настройка базы данных

**ВАЖНО:** В production используйте PostgreSQL, НЕ SQLite!

1. Создайте базу данных PostgreSQL в Timeweb Cloud
2. Получите строку подключения (DATABASE_URL)
3. Добавьте её в переменные окружения приложения

Формат DATABASE_URL:
```
postgresql://username:password@host:5432/database_name
```

### 5. Настройка CORS

Укажите точные домены вашего приложения:

```env
CORS_ORIGINS=https://yourdomain.com,https://www.yourdomain.com
```

**НЕ используйте** `*` или `localhost` в production!

### 6. Проверка работы приложения

После настройки переменных окружения:

1. **Перезапустите приложение** в Timeweb Cloud (если нужно)
2. **Откройте URL** вашего приложения
3. **Войдите** с учетными данными:
   - Username: `admin`
   - Password: (тот, что указан в `ADMIN_PASSWORD`)

### 7. Проверка логов

В панели Timeweb Cloud:

1. Перейдите в раздел **"Логи"** вашего приложения
2. Проверьте наличие ошибок
3. Убедитесь, что приложение запустилось успешно

### 8. Тестирование функций

Проверьте работу основных функций:

- ✅ Вход в систему
- ✅ Дашборд загружается
- ✅ Создание оборудования
- ✅ Создание нарушений
- ✅ AI генерация (если настроена)
- ✅ Экспорт таблиц

## ⚠️ Важные замечания:

1. **База данных:** Используйте PostgreSQL, не SQLite!
2. **HTTPS:** Убедитесь, что SSL сертификат настроен
3. **Пароль администратора:** Измените дефолтный пароль!
4. **CORS:** Настройте только для ваших доменов
5. **Резервное копирование:** Настройте автоматическое резервное копирование БД

## 🔧 Если что-то не работает:

1. **Проверьте логи** в панели Timeweb Cloud
2. **Убедитесь**, что все переменные окружения установлены
3. **Проверьте**, что база данных доступна
4. **Убедитесь**, что порты открыты (обычно 3000 для Next.js)

## 📞 Поддержка:

Если возникли проблемы:
- Проверьте логи приложения
- Убедитесь, что все переменные окружения настроены
- Проверьте подключение к базе данных
