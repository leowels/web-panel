# Очистка кэша

Если вы видите старую версию приложения, попробуйте следующие способы:

## 1. Очистка кэша браузера

### Chrome/Edge:
- Нажмите `Ctrl + Shift + Delete`
- Выберите "Изображения и файлы в кэше"
- Нажмите "Удалить данные"

### Или жесткая перезагрузка:
- `Ctrl + F5` (Windows/Linux)
- `Cmd + Shift + R` (Mac)

## 2. Очистка кэша Next.js

Остановите сервер и выполните:

```bash
# Удалите папку .next
rm -rf .next

# Или на Windows:
rmdir /s /q .next

# Перезапустите сервер
npm run dev
```

## 3. Очистка node_modules (если проблемы с зависимостями)

```bash
# Удалите node_modules и package-lock.json
rm -rf node_modules package-lock.json

# Переустановите зависимости
npm install

# Перезапустите сервер
npm run dev
```

## 4. Очистка localStorage браузера

Откройте консоль браузера (F12) и выполните:

```javascript
localStorage.clear()
sessionStorage.clear()
location.reload()
```

## 5. Проверка в режиме инкогнито

Откройте приложение в режиме инкогнито/приватном режиме браузера - это поможет определить, связана ли проблема с кэшем.

## 6. Проверка, что сервер перезапущен

Убедитесь, что:
- Backend сервер запущен (`python run.py` в папке `backend`)
- Frontend сервер запущен (`npm run dev` в корневой папке)
- Оба сервера перезапущены после изменений
