## 🐳 Деплой Frontend (Next.js)

### Шаг 3: Создание приложения Frontend в Timeweb Cloud

1. **Войдите в панель Timeweb Cloud**
2. **Создайте новое приложение:**
   - Тип: **Docker контейнер**
   - Источник: **Git репозиторий** (укажите ваш репозиторий)
   - Dockerfile: **Dockerfile** (в корне проекта)
   - Порт: **3000**

### Шаг 4: Настройка переменных окружения для Frontend

В настройках приложения добавьте:

```env
NODE_ENV=production
PORT=3000
NEXT_PUBLIC_API_URL=https://api.yourdomain.com
```

**Важно:** Замените `yourdomain.com` на ваш реальный домен!

### Шаг 5: Запуск Frontend

1. Сохраните настройки
2. Запустите сборку/деплой
3. Дождитесь завершения (5-10 минут)
4. Проверьте статус: должно быть "Запущено"

## 🐍 Деплой Backend (FastAPI)

### Шаг 6: Создание приложения Backend в Timeweb Cloud

1. **Создайте второе приложение:**
   - Тип: **Docker контейнер**
   - Источник: **Git репозиторий** (тот же репозиторий)
   - Dockerfile: **backend/Dockerfile**
   - Порт: **8000**

### Шаг 7: Настройка базы данных PostgreSQL

1. **Создайте базу данных PostgreSQL в Timeweb Cloud:**
   - Перейдите в раздел "Базы данных"
   - Создайте новую PostgreSQL базу
   - Запомните: host, port, database, username, password

2. **Сформируйте DATABASE_URL:**
   ```
   postgresql://username:password@host:5432/database_name
   ```

### Шаг 8: Генерация SECRET_KEY

Выполните локально:
```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Скопируйте сгенерированный ключ.

### Шаг 9: Настройка переменных окружения для Backend

В настройках Backend приложения добавьте:

```env
# ОБЯЗАТЕЛЬНО:
SECRET_KEY=<сгенерированный_ключ>
DATABASE_URL=postgresql://user:password@host:5432/dbname
CORS_ORIGINS=https://yourdomain.com
ENVIRONMENT=production
PORT=8000
ADMIN_PASSWORD=<сильный_пароль>

# Опционально (для AI):
AI_PROVIDER=timeweb
AI_API_KEY=<ваш_ключ>
AI_BASE_URL=<url_вашего_агента>
AI_AGENT_ACCESS_ID=<access_id>
```

**Важно:**
- Замените `yourdomain.com` на ваш реальный домен
- Используйте реальные данные PostgreSQL
- Установите сильный пароль для администратора

### Шаг 10: Запуск Backend

1. Сохраните настройки
2. Запустите сборку/деплой
3. Дождитесь завершения (10-15 минут для первой сборки)
4. Проверьте статус: должно быть "Запущено"

## 🆘 Решение проблем

### Если Frontend не запускается:
- Проверьте логи
- Убедитесь, что `NEXT_PUBLIC_API_URL` указан правильно
- Проверьте, что порт 3000 открыт

### Если Backend не запускается:
- Проверьте логи
- Убедитесь, что `SECRET_KEY` установлен
- Проверьте подключение к базе данных (`DATABASE_URL`)
- Убедитесь, что порт 8000 открыт

### Если не работает подключение к API:
- Проверьте `CORS_ORIGINS` - должен содержать домен Frontend
- Проверьте `NEXT_PUBLIC_API_URL` - должен указывать на Backend
- Проверьте, что оба контейнера запущены
