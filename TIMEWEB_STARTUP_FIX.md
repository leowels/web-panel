# 🔧 Решение проблемы запуска в Timeweb Cloud

## Проблема: Приложение не запускается после сборки

Если приложение находится в статусе "Ожидание" или не запускается, проверьте следующее:

### 1. Проверьте команду запуска в Timeweb Cloud

В настройках приложения должна быть указана правильная команда запуска:

#### Для Next.js (Frontend):
```bash
npm start
```

Или если используется production режим:
```bash
NODE_ENV=production npm start
```

#### Для Backend (FastAPI):
```bash
cd backend && python run.py
```

Или через uvicorn:
```bash
cd backend && uvicorn main:app --host 0.0.0.0 --port 8000
```

### 2. Проверьте порт

Убедитесь, что приложение слушает правильный порт:

- **Next.js** должен слушать порт, указанный в переменной окружения `PORT` (по умолчанию 3000)
- **Backend** должен слушать порт, указанный в переменной окружения `PORT` (по умолчанию 8000)

Добавьте в переменные окружения:
```env
PORT=3000  # для Next.js
# или
PORT=8000  # для Backend
```

### 3. Проверьте обязательные переменные окружения

Приложение может не запускаться, если отсутствуют обязательные переменные:

#### Для Backend (обязательно):
```env
SECRET_KEY=<должен_быть_установлен>
DATABASE_URL=<должен_быть_установлен>
```

#### Для Next.js:
```env
NEXT_PUBLIC_API_URL=<должен_быть_установлен>
```

### 4. Проверьте логи

В панели Timeweb Cloud:
1. Перейдите в раздел **"Логи"** вашего приложения
2. Проверьте последние записи
3. Ищите ошибки типа:
   - `SECRET_KEY not found`
   - `DATABASE_URL not found`
   - `Port already in use`
   - `Module not found`

### 5. Проверьте health check

Если приложение запускается, но не отвечает, проверьте health check endpoint:

- Backend: `http://your-domain:8000/api/health`
- Frontend: `http://your-domain:3000`

### 6. Типичные проблемы и решения

#### Проблема: "SECRET_KEY not found"
**Решение:** Добавьте переменную окружения `SECRET_KEY`

#### Проблема: "DATABASE_URL not found"
**Решение:** Добавьте переменную окружения `DATABASE_URL` с правильной строкой подключения

#### Проблема: "Port already in use"
**Решение:** Измените порт в переменной окружения `PORT`

#### Проблема: "Module not found"
**Решение:** Убедитесь, что все зависимости установлены (`npm install` для frontend, `pip install -r requirements.txt` для backend)

### 7. Проверьте конфигурацию Dockerfile

Если используется Docker, убедитесь, что Dockerfile правильно настроен:

```dockerfile
# Для Next.js
CMD ["npm", "start"]

# Для Backend
CMD ["python", "backend/run.py"]
```

### 8. Перезапустите приложение

После настройки переменных окружения:
1. Сохраните изменения
2. Перезапустите приложение в панели Timeweb Cloud
3. Подождите 1-2 минуты
4. Проверьте статус

### 9. Проверьте ресурсы

Убедитесь, что у приложения достаточно ресурсов:
- RAM (минимум 512MB для Next.js, 256MB для Backend)
- CPU
- Дисковое пространство

### 10. Контакты поддержки

Если проблема не решается:
1. Скопируйте логи из панели Timeweb Cloud
2. Проверьте все переменные окружения
3. Обратитесь в поддержку Timeweb Cloud с логами

---

**Важно:** Приложение должно запуститься в течение 1-2 минут после настройки всех переменных окружения и перезапуска.
