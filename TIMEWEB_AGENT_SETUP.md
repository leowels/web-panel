# Настройка Timeweb Cloud AI-агента

Система поддерживает работу с AI-агентами Timeweb.Cloud через их API.

## Шаги настройки:

### 1. В личном кабинете Timeweb.Cloud:

1. **Создайте/выберите AI-агента:**
   - Перейдите в раздел "AI-агенты"
   - Создайте нового агента или выберите существующего
   - Настройте промпт и параметры агента

2. **Получите Access ID агента:**
   - В настройках агента найдите "Access ID"
   - Скопируйте этот ID

3. **Создайте API-ключ:**
   - Перейдите в раздел "API-ключи" или "Настройки API"
   - Создайте новый API-ключ
   - Скопируйте ключ (он показывается только один раз!)

### 2. В веб-интерфейсе системы:

1. **Войдите как администратор**

2. **Перейдите в Настройки → Системные настройки**

3. **В разделе "AI Конфигурация" укажите:**

   - **AI Провайдер:** `timeweb`
   - **AI API Ключ:** Вставьте ваш API-ключ из Timeweb.Cloud
   - **Timeweb Agent Access ID:** Вставьте Access ID вашего агента
   - **AI Base URL:** Оставьте пустым (для агентов не используется)
   - **AI Модель:** Оставьте пустым (для агентов не используется)

4. **Нажмите "Сохранить"** для каждой настройки

## Как это работает:

- Если указан **Agent Access ID**, система использует API агентов Timeweb.Cloud (`/ai/agents/chat`)
- Если **Agent Access ID** не указан, используется OpenAI-совместимый API Timeweb.Cloud
- Все запросы идут через бэкенд, ключи не попадают в браузер

## Использование:

После настройки AI-агент будет использоваться для:
- ✅ Генерации нарушений
- ✅ Генерации актов
- ✅ Поиска в базе знаний
- ✅ Универсальной генерации текста (кнопка "ИИ Помощник")

## Поддержка контекста чата:

Для агентов Timeweb.Cloud поддерживается контекст чата через `parentMessageId`. Это позволяет вести диалог с агентом, сохраняя историю разговора.

## Примеры использования:

### Через API:

```python
POST /api/ai/generate
{
  "prompt": "Создай описание нарушения",
  "context": "Кран #123, цех №2",
  "parent_message_id": "optional-message-id"  # Для контекста чата
}
```

### Через веб-интерфейс:

1. Нажмите кнопку "ИИ Помощник" в шапке
2. Введите запрос
3. При необходимости добавьте контекст
4. Нажмите "Сгенерировать"
