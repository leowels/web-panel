## Что нужно сделать:

### 1. Закоммитьте изменения:

```bash
git add docker-entrypoint.sh Dockerfile.full
git commit -m "fix: улучшен запуск Backend с диагностикой"
git push
```

### 2. Пересоберите контейнер в Timeweb Cloud

После push контейнер должен автоматически пересобраться.

### 3. Проверьте логи

После пересборки в логах должны быть:

```

==========================================

...

...

Запуск: python run.py
Backend запущен с PID: X
✓ Backend успешно запущен
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 4. Если Backend все еще не запускается

Проверьте в логах:
- Есть ли ошибки при запуске Python?
- Есть ли ошибки подключения к БД?
- Есть ли ошибки импорта модулей?

## Возможные проблемы:

### Проблема: "Module not found"
**Решение:** Проверьте, что все зависимости установлены в requirements.txt

### Проблема: "DATABASE_URL not found"
**Решение:** Убедитесь, что переменная DATABASE_URL установлена

### Проблема: "SECRET_KEY not found"
**Решение:** Убедитесь, что переменная SECRET_KEY установлена

### Проблема: Ошибка подключения к БД
**Решение:** Проверьте DATABASE_URL и доступность базы данных
