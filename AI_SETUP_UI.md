# Настройка AI через веб-интерфейс

Теперь все настройки AI можно настроить через веб-интерфейс без изменения кода!

## Как настроить:

1. **Войдите как администратор** в систему

2. **Перейдите в раздел "Настройки"** (в меню слева)

3. **Откройте вкладку "Системные настройки"** (доступна только для админов)

4. **В разделе "AI Конфигурация"** настройте:

   - **AI Провайдер**: Выберите `OpenAI` или `Timeweb Cloud AI`
   - **AI API Ключ**: Вставьте ваш API ключ
   - **AI Base URL**: Для Timeweb Cloud укажите endpoint (для OpenAI оставьте пустым)
   - **AI Модель**: Укажите модель (например: `gpt-3.5-turbo`, `gpt-4`)

5. **Нажмите "Сохранить"** для каждой настройки

## Где используются AI настройки:

- ✅ Генерация нарушений (`/api/violations/ai/generate`)
- ✅ Генерация актов (`/api/acts/{id}/generate`)
- ✅ Поиск в базе знаний (`/api/knowledge/ai/search`)

## Приоритет настроек:

1. **Настройки из базы данных** (через веб-интерфейс) - **высший приоритет**
2. Переменные окружения (`.env` файл)
3. Дефолтные значения

## После изменения настроек:

Настройки применяются сразу после сохранения. Кэш AI клиента автоматически очищается.

## Безопасность:

- API ключи хранятся в базе данных в зашифрованном виде
- Доступ к настройкам имеют только администраторы
- Все изменения логируются в аудит-логе
