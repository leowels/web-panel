# 🔍 Отладка запуска Backend

## Проблема: Backend не запускается

## Проверка

### 1. Проверьте логи контейнера

В Timeweb Cloud откройте логи и ищите:
- `=== Запуск Backend на порту 8000 ===`
- `Backend запущен с PID: X`
- `INFO: Uvicorn running on http://0.0.0.0:8000`

### 2. Возможные ошибки

#### Ошибка: "Директория /app/backend не найдена"
**Решение:** Проверьте, что Backend скопирован в Dockerfile

#### Ошибка: "Файл run.py не найден"
**Решение:** Проверьте структуру файлов в контейнере

#### Ошибка: "Python не найден"
**Решение:** Проверьте базовый образ Dockerfile

#### Ошибка: "Backend процесс завершился"
**Решение:** Проверьте переменные окружения (SECRET_KEY, DATABASE_URL)

### 3. Проверьте переменные окружения

Убедитесь, что установлены:
```env
SECRET_KEY=<ключ>
DATABASE_URL=postgresql://...
PORT=8000
ENVIRONMENT=production
```

### 4. Проверьте структуру файлов

В Dockerfile должно быть:
```dockerfile
COPY backend/ ./backend/
```

### 5. Альтернативное решение: Запуск через supervisor

Если проблема сохраняется, можно использовать supervisor для управления процессами.

---

**Следующий шаг:** Проверьте логи контейнера на наличие ошибок! 🔍
