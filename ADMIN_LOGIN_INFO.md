# 🔐 Информация для входа администратора

## Учетные данные:

**Username:** `admin`

**Password:** 
- Если установлена переменная `ADMIN_PASSWORD` → используйте её значение
- Если НЕ установлена → используйте `admin123` (по умолчанию)

## Проверка:

1. Откройте консоль браузера (F12)
2. Попробуйте войти
3. Посмотрите ошибку в консоли или Network tab

## Если не работает:

1. **Проверьте переменную ADMIN_PASSWORD:**
   - В Timeweb Cloud должна быть установлена переменная `ADMIN_PASSWORD`
   - Или используйте пароль по умолчанию: `admin123`

2. **Проверьте логи Backend:**
   - Должна быть строка: `✓ Пользователь admin создан`
   - Или: `Пользователь admin уже существует`

3. **Проверьте API:**
   - Откройте: `https://your-domain.com/api/health`
   - Должно вернуть: `{"status": "ok"}`

4. **Попробуйте через API напрямую:**
   ```bash
   curl -X POST https://your-domain.com/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"admin123"}'
   ```

## Сброс пароля админа:

Если нужно сбросить пароль, установите переменную `ADMIN_PASSWORD` с новым паролем и перезапустите приложение.

**ВАЖНО:** После первого запуска пользователь admin создается один раз. Если нужно изменить пароль существующего админа, нужно сделать это через API или напрямую в БД.
