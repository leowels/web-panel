# 🔧 Исправление ошибки ERR_CONNECTION_REFUSED

## Проблема:
Frontend пытался обращаться к `http://localhost:8000/api/auth/login` напрямую из браузера, но это не работает, потому что:
- В браузере `localhost:8000` - это ваш компьютер, а не контейнер
- Backend работает внутри контейнера на `localhost:8000`, но браузер не может к нему подключиться напрямую

## Решение:
1. ✅ Убрал `NEXT_PUBLIC_API_URL` из Dockerfile (Build Arguments)
2. ✅ Исправил все компоненты, чтобы они использовали **относительный путь** в браузере
3. ✅ Next.js автоматически проксирует `/api/*` на Backend через `rewrites` в `next.config.js`

## Как это работает:
- **В браузере:** Frontend делает запрос к `/api/auth/login` (относительный путь)
- **Next.js:** Автоматически проксирует `/api/*` → `http://localhost:8000/api/*` (внутри контейнера)
- **Backend:** Получает запрос и обрабатывает его

## Что нужно сделать:
1. **Пересобрать Docker образ** (без `NEXT_PUBLIC_API_URL` в Build Arguments)
2. **Перезапустить контейнер**
3. **Попробовать войти:**
   - Username: `admin`
   - Password: `admin123` (или значение из `ADMIN_PASSWORD`)

## Проверка:
После пересборки в логах должно быть:
- `✓ Пользователь admin создан` или `Пользователь admin уже существует`
- Frontend должен обращаться к `/api/auth/login` (без `localhost:8000`)
