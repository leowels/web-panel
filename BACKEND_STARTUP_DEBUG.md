# 🔍 Диагностика запуска Backend

## Проблема: Backend не виден в логах

В логах видно только Frontend, но нет сообщений от Backend.

## Что исправлено:

1. ✅ **Убрано `set -e`** - теперь скрипт не останавливается при первой ошибке
2. ✅ **Улучшен вывод логов** - Backend запускается с перенаправлением вывода
3. ✅ **Добавлена диагностика** - если Backend падает, он запускается напрямую для показа ошибок

## Что нужно сделать:

### 1. Закоммитьте изменения:

```bash
git add docker-entrypoint.sh
git commit -m "fix: улучшена диагностика запуска Backend"
git push
```

### 2. Пересоберите контейнер

После push контейнер должен автоматически пересобраться.

### 3. Проверьте логи

После пересборки в логах должны быть:

**Если Backend запускается:**
```
=== Запуск Backend на порту 8000 ===
Запуск: python run.py
Backend запущен с PID: X
INFO:     Uvicorn running on http://0.0.0.0:8000
```

**Если Backend падает:**
```
ОШИБКА: Backend процесс завершился!
Попытка запуска Backend напрямую для диагностики...
[Здесь будут видны ошибки Python]
```

## Возможные причины:

### 1. Отсутствуют переменные окружения

Проверьте, что установлены:
```env
SECRET_KEY=<ключ>
DATABASE_URL=postgresql://...
PORT=8000
```

### 2. Ошибка подключения к БД

Проверьте `DATABASE_URL` - он должен быть правильным.

### 3. Ошибка импорта модулей

Проверьте, что все зависимости установлены в `requirements.txt`.

### 4. Ошибка в коде Backend

Проверьте логи - там должны быть traceback ошибок.

## Альтернативное решение

Если проблема сохраняется, можно запустить Backend отдельно:

1. Создайте второй контейнер для Backend
2. Используйте `backend/Dockerfile`
3. Настройте переменные окружения
4. Обновите `NEXT_PUBLIC_API_URL` на URL Backend контейнера
