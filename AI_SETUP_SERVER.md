# Настройка AI на сервере

## Быстрая настройка через веб-интерфейс

1. **Войдите в систему** как администратор
2. Перейдите в **Настройки** → **Системные настройки**
3. Найдите раздел **AI Конфигурация**

## Параметры для Timeweb Cloud AI

### 1. AI Провайдер
Выберите: **`timeweb`** (или оставьте `openai`, если URL содержит `timeweb.cloud`)

### 2. AI API Ключ
Вставьте ваш **API ключ** из панели Timeweb Cloud:
- Откройте панель управления вашим AI-агентом в Timeweb Cloud
- Скопируйте **API ключ** (обычно начинается с `tw_` или похож на длинную строку)
- Вставьте в поле "AI API Ключ"

### 3. AI Base URL (OpenAI URL)
**ВАЖНО!** Это самый важный параметр!

Вставьте URL из раздела **"OpenAI URL"** в настройках вашего агента:
```
https://agent.timeweb.cloud/api/v1/cloud-ai/agents/5678b8cd-4bea-412f-81ca-62e92a38aa49/v1
```

**Где найти:**
- Откройте панель управления вашим AI-агентом в Timeweb Cloud
- Найдите раздел **"OpenAI URL"** или **"API Endpoint"**
- Скопируйте полный URL (должен содержать `/agents/` и `/v1` в конце)

### 4. AI Модель (опционально)
Оставьте пустым или укажите модель, если требуется.
Для агентов Timeweb Cloud модель определяется автоматически.

### 5. Timeweb Agent Access ID (опционально)
Можно оставить пустым. Используется только для справки.

## Сохранение настроек

1. Нажмите **"Сохранить"** для каждого параметра
2. После сохранения всех параметров нажмите **"Тестировать AI"**
3. Если тест успешен - все готово!

## Настройка через переменные окружения (альтернатива)

Если вы предпочитаете использовать переменные окружения, добавьте в `.env` или в настройки сервера:

```bash
AI_PROVIDER=timeweb
AI_API_KEY=ваш_api_ключ_из_панели_timeweb
AI_BASE_URL=https://agent.timeweb.cloud/api/v1/cloud-ai/agents/5678b8cd-4bea-412f-81ca-62e92a38aa49/v1
AI_MODEL=gpt-3.5-turbo  # опционально
```

## Проверка работы

После настройки:
1. Перейдите в раздел **AI** (если есть в интерфейсе)
2. Или используйте функцию генерации в других разделах (акты, нарушения)
3. Если видите ошибку - проверьте:
   - Правильность API ключа
   - Правильность Base URL (должен быть полный URL с `/v1` в конце)
   - Что агент активен в панели Timeweb Cloud

## Частые ошибки

### Ошибка: "max_tokens is not supported"
✅ **Исправлено!** Теперь код автоматически использует `max_completion_tokens` для Timeweb Cloud.

### Ошибка: "404 Not Found"
- Проверьте, что Base URL правильный (должен быть из раздела "OpenAI URL")
- Убедитесь, что URL заканчивается на `/v1`
- Проверьте, что агент активен в панели Timeweb Cloud

### Ошибка: "Invalid API key"
- Проверьте, что API ключ скопирован полностью (без пробелов)
- Убедитесь, что используете правильный ключ из панели агента

## Что было исправлено

1. ✅ Автоматическое определение Timeweb Cloud по URL (даже если провайдер указан как "openai")
2. ✅ Автоматическое использование `max_completion_tokens` вместо `max_tokens` для Timeweb Cloud
3. ✅ Улучшенная обработка ошибок с понятными сообщениями
