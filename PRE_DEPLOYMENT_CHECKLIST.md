## 🚨 Критичные моменты перед деплоем

1. **НЕ используйте SQLite в production!** Используйте PostgreSQL или MySQL
2. **НЕ храните секреты в коде!** Все в переменных окружения
3. **НЕ используйте `*` в CORS!** Укажите конкретные домены
4. **Включите HTTPS!** Без SSL сертификата не деплойте
5. **Настройте резервное копирование!** Без бэкапов не деплойте
6. **Проверьте права доступа!** Убедитесь, что только нужные пользователи имеют доступ

## 📝 Пример .env для production

```env
# Backend
ENVIRONMENT=production
DEBUG=False
SECRET_KEY=<сильный_случайный_ключ_минимум_32_символа>
DATABASE_URL=postgresql://user:password@host:5432/dbname
JWT_SECRET_KEY=<сильный_случайный_ключ>
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30

# AI
AI_PROVIDER=openai
AI_API_KEY=<ваш_api_ключ>
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4

# CORS
CORS_ORIGINS=https://yourdomain.com,https://www.yourdomain.com

# Frontend
NEXT_PUBLIC_API_URL=https://api.yourdomain.com
```
