# Исправление ошибки импорта

## Проблема
При запуске сервера возникает ошибка:
```
ImportError: attempted relative import beyond top-level package
```

## Решение

### Вариант 1: Запуск через run.py (рекомендуется)
```bash
cd backend
python run.py
```

### Вариант 2: Запуск через uvicorn напрямую
```bash
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### Вариант 3: Запуск как модуль
```bash
# Из корневой директории проекта
python -m backend.main
```

## Важно!
Сервер должен запускаться **из директории `backend`**, чтобы относительные импорты работали правильно.

Если ошибка сохраняется, проверьте:
1. Запущен ли сервер из директории `backend`
2. Есть ли файл `__init__.py` в директории `backend`
3. Есть ли файл `__init__.py` в директории `backend/routers`
4. Проверьте вывод консоли при запуске - там должны быть сообщения об ошибках импорта
