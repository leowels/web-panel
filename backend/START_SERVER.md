# Инструкция по запуску сервера

## Правильный способ запуска

### Вариант 1: Через run.py (РЕКОМЕНДУЕТСЯ) ⭐
```bash
cd backend
python run.py
```

Этот способ использует uvicorn и правильно обрабатывает импорты.

### Вариант 2: Через uvicorn напрямую
```bash
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### ⚠️ Важно: НЕ запускайте `python main.py` напрямую!

Используйте только `python run.py` или `uvicorn main:app`.

## Важно!

**Всегда запускайте сервер из директории `backend`**, иначе импорты не будут работать правильно.

## Проверка работы

После запуска сервера:
1. Откройте `http://localhost:8000/docs` - должна открыться Swagger документация
2. Проверьте эндпоинт `/api/health` - должен вернуть `{"status": "ok"}`
3. Проверьте эндпоинт `/api/equipment` - должен вернуть список оборудования (требует авторизации)

## Решение проблем

Если видите ошибки импорта:
1. Убедитесь, что вы в директории `backend`
2. Проверьте, что все файлы `__init__.py` на месте
3. Перезапустите сервер
4. Проверьте вывод консоли на наличие ошибок
