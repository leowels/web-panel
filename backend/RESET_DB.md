# Сброс базы данных

Если вы получили ошибку о несуществующих колонках, это означает, что база данных была создана со старой схемой.

## Решение

1. **Удалите файл базы данных:**
   ```bash
   cd backend
   rm rostekhnadzor.db  # Linux/Mac
   # или
   del rostekhnadzor.db  # Windows
   ```

2. **Перезапустите сервер:**
   ```bash
   python run.py
   ```

База данных будет автоматически пересоздана с актуальной схемой при первом запуске.

## Внимание!

⚠️ **Это удалит все данные!** Используйте только в разработке.

Для продакшена используйте миграции Alembic.
