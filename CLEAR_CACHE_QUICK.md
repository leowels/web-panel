# 🚀 Быстрая очистка кэша

## Шаг 1: Остановите серверы
Нажмите `Ctrl+C` в обоих терминалах (frontend и backend)

## Шаг 2: Очистите кэш Next.js
```bash
# Windows PowerShell:
Remove-Item -Recurse -Force .next

# Или вручную удалите папку .next
```

## Шаг 3: Очистите кэш браузера
1. Откройте DevTools (F12)
2. Правой кнопкой на кнопку обновления страницы
3. Выберите "Очистить кэш и жесткая перезагрузка"

Или просто: `Ctrl + Shift + Delete` → Очистить кэш

## Шаг 4: Очистите localStorage
В консоли браузера (F12):
```javascript
localStorage.clear()
sessionStorage.clear()
location.reload()
```

## Шаг 5: Перезапустите серверы
```bash
# Терминал 1 - Backend:
cd backend
python run.py

# Терминал 2 - Frontend:
npm run dev
```

## Шаг 6: Откройте в режиме инкогнито
Или используйте жесткую перезагрузку: `Ctrl + F5`

---

**Если не помогло:**
1. Проверьте консоль браузера (F12) на наличие ошибок
2. Проверьте, что все компоненты дашборда загружаются
3. Убедитесь, что вы на странице `/dashboard`, а не на другой
